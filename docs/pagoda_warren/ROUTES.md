# Pagoda Warren — Route Catalogue

All gameplay routes designed for the **Pagoda Warren** event — the fused pagoda corridor the parrot threads. Each route is one continuous stretch (~0.45s per pagoda) authored to teach or test a specific one-button maneuver, and is checked against the warren's passability rules. Every route uses the approved Gentle-Sine-Tube pagoda look.

**35 routes** across five tiers, rated **1–10** for challenge.

## Design notes

- **How long is a warren?** At ~0.45s per pagoda, routes run ~10–29s — a distinct 'place' you fly through, not a couple of gates. Intense routes are kept short (~10s) so they thrill rather than exhaust; the medleys run longest.
- **Fairness rule.** The forgiving routes guarantee a continuous **≥90px channel** (~3 bird-heights) the whole way; the aggressive-drop set deliberately breaks that to reach terminal velocity, which is why it rates 8–10.
- **Physics.** Gravity 1600 → terminal 700px/s; one flap rises ~84px. A downward drop can be far steeper than a climb because the parrot falls fast on its own — the steepest *fair* drop is a controlled ~80px/pagoda fall, not the ~136px/pagoda free-fall.
- **Source.** Routes live in `tools/render_warren_routes*.py`; this catalogue is generated by `tools/gen_routes_md.py`. No game code is affected — these are look-dev/design artifacts.
