# RAKTA-AMBU — Round 1 critique

The hero is appealing and the central face charming, but the silhouette reads wrong: at blackout and 32px
this registers as a Mukha-style radiating starburst/fan of straight limbs, NOT a forked branching canopy —
the concept's whole reason to exist. The encrusted skulls also pile into a white belt across the mid-arms.

## Ranking (strongest → weakest)
1. **Central face + accent restraint (STRONG).** Salmon-coral eye-cores read warm + dull, never Mukha hot
   magenta; indigo body is genuinely indigo, not Yurei cyan. Palette discipline is the win. Keep it.
2. **Pillar (GOOD).** Bottom-rooted, mirrored, clear trunk base, no taper risk. Minor work only.
3. **Proportion (PARTIAL).** Spreads wider than tall, but via long straight rays, not a widening canopy
   mass — reads "fan," not "monumental tree."
4. **Encrusted-skull cluster (WEAK — self-flagged, confirmed).** ~10+ near-identical full-white skulls form
   a horizontal white belt across mid-arms + a dense triple-mass on the crown. Muddies the read.
5. **Silhouette tell (FAILS — gating).** Blackout + both 32px chips read as discrete radiating spokes = a
   Mukha starburst. The forked/dendritic canopy is not legible.

## Round-2 punch list (prioritized)
1. **Re-construct arms as forked BRANCHES (gates everything).** (a) taper each arm thick base→thin tip;
   (b) each arm visibly splits into 2 at one fork, then those split once more (cap at 2) — currently splits
   happen only at the very tips as polyp clusters, so the blackout sees solid spokes; (c) STAGGER fork
   heights so junctions sit at different radii (uniform spoke length is what makes it a fan); (d) knobbly
   width variation along each branch. Re-render blackout: must read as a knobbly branching crown, not 16 rays.
2. **Close the canopy top.** Shorten the longest rays ~15%; fatten + cluster outer fork-tips into a domed
   lumpy crown so WIDTH = mass, not ray length — that sells "monumental by width" vs "wide fan."
3. **Fix the skull belt.** Cut to 4–5 skulls; sink them DEEPER into the lower fork crotches (dark
   Y-junctions); drop value to bone-grey ~`(168,170,162)` not pure white (encrusted texture, not a
   necklace); reserve the brightest skull only for the crown center.
4. **Re-shoot blackout + both 32px chips** after 1–3; outer canopy outline must carry, zero interior
   skull/tracery detail surviving at 32px.
5. **NIGHT legibility.** Give the trunk-base a hair of cool rim-light so the silhouette doesn't dissolve
   bottom-up into the dark ground at night.
6. **Pillar.** Add 1–2 staggered branch knobs so it echoes the new dendritic language, not a plain post.
7. Pull the upper-arm rim-sheen down ~one value step so the coral face stays the single focal point.

## Distinctness (§6) — AT RISK
As drawn, too close to Mukha (radial fan) and leans toward Asthi-Garuda's spread. The fork/taper/canopy
fixes are what separate it; confirm against Mukha round_2 side-by-side in round 2.

The single change that turns "fan" into "tree": width taper + STAGGERED bifurcation, not equal-length spokes.
