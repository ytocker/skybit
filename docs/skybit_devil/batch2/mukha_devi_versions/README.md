# Mukha-Devi versions — many-armed bone-goddess bosses

![Mukha-Devi versions showcase](./showcase.png)

Five new epic bosses spun off **Mukha-Devi** — the six-armed wrathful bone-mother from the
[`citipati_versions`](../citipati_versions/README.md) brood (so this is a spin-off *of* a spin-off).
**Mukha-Devi is the Original;** every boss here keeps her DNA — **multi-arm + skull-crown/tiara +
elaborate arm-end ornaments with tiny skulls among them** — but takes a distinct solid-black silhouette
KIND, and the five deliberately span both a **proportion** axis (elevated-chibi → monumental) and a
**theme** axis (pure skeletal → bone-core + a distinct accent).

The showcase row reads left→right as that chibi→monumental story, with Mukha-Devi set apart as the
REFERENCE tile.

- **Original:** Mukha-Devi — six-armed bone-mother (radial-fan) —
  [../citipati_versions/mukha_devi](../citipati_versions/mukha_devi)
- **Asha-Mukti** — lotus bloom-mandorla saint; a tiny carved idol whose eight arms close into a pointed
  almond aureole, saffron→peach bloom, skulls in the lowest lotus-pods — *elevated-chibi · lotus* —
  final round_3 (folds in the final critique) — [./asha_mukti](./asha_mukti)
- **Nagini-Devi** — serpent hood-ring naga-queen; six arms reared into cobra-hoods haloing the skull,
  oxidized verdigris over dominant bronze, skulls in alternating jaws — *mid · serpent* — **SHIP-READY**
  (final round_2) — [./nagini_devi](./nagini_devi)
- **Chandra-Mata** — lunar crescent-arc mother; slim, arms cupped into a wide low crescent-smile under a
  single rising moon-horn, desaturated grey-lilac (the brood's only night-tuned accent) —
  *mid-tall · lunar* — final round_3 — [./chandra_mata](./chandra_mata)
- **Rakta-Ambu** — coral-tree bone-canopy; arms forking into a dendritic tree-crown, monumental-by-width,
  briny indigo with a dull salmon-coral heart, skulls encrusted in the lower forks —
  *mid-tall→monumental · coral* — final round_3 — [./rakta_ambu](./rakta_ambu)
- **Asthi-Samrat** — temple-pylon colossus; twelve arms stacked as a rigid stepped arm-grid topped with
  skull-pole finials, **pure austere bone** (cold socket-pin the only non-bone note) —
  *monumental · pure-skeletal* — final round_3 — [./asthi_samrat](./asthi_samrat)

## Status
Nagini-Devi earned a SHIP-READY at round 2. The other four matured through the full GD3/AD2 design-loop
budget (designer → critic → designer → critic → **designer**), so each final round_3 folds in its second
critique but did not get a formal post-round-3 ship-ready sign-off — the round-2 critiques each judged them
"one fix away / land this and it ships," and the round-3 designer self-checks report those fixes landed.
Per-concept `critique_round1.md` / `critique_round2.md` hold the full record.
