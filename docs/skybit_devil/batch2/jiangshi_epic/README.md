# Jiangshi-epic — 5 inspired-by bosses

Five late-game boss concepts in the lineage of the shipped **Jiangshi** (the
talisman-sealed hopping Qing corpse), each carrying the undead-folklore theme
into a different culture's revenant and leading on its own silhouette. All
ship-ready. Design-only — not yet wired into the spawn roster.

## Lineage

Each boss is an inspired-by descendant of the shipped **Jiangshi** — the
undead-folklore vein widened across cultures (Tibetan charnel lord, Chinese
sancai tomb beast, ghost-marriage bride, Korean totem-post, South-Asian
vetala). They reuse the same procedural pipeline (flat saturated fills, hard
ink keyline, dark-core→fill→top-left sheen, mirrored pillar gap-caps) so they
read at 32px gameplay scale like the reference.

Each concept dir also holds its full round-by-round trail (`round_N.png` +
`critique_roundN.md`) and standalone renderer. Design-only — not wired into the
spawn roster.
