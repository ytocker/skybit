VERDICT: ITERATE

A strong, confident round 1 — the freshest sister in the brood is landing. Tiger-pelt grammar is
genuinely new, palette clean and unclaimed, locked motif almost entirely present. Not SHIP-READY
because the 32px read fails on the one thing it was meant to nail (the stripe-sash), the value
ladder is compressed at the top, and a couple of locked sub-items are weak. All fixable in one pass.

## Strongest / weakest
- **Strongest:** hero crown row + tiger-ear flank. 5-skull arc + tiara-band both read; green-gold
  third-eye is a clean cool focal on the warm mass; ears spring from BEHIND the centre skull (flank,
  don't cap). Distinctness vs vajra_rakta unambiguous (hide-sash, no brocade, no flame-ring).
- **Weakest:** the 32px two-scale read. The named carrier — the bold tawny/black diagonal stripe-
  sash — does NOT carry: at true 32px it's a thin low-contrast orange thread, and the boss reads as
  a generic six-arm bone-thing.

## FIX (ranked)
1. **Make the stripe-sash carry the 32px read (#1 job).** Widen the band to a 2-3px THICK diagonal
   at 32px and pump stripe contrast: alternate FULL black-stripe blocks against tawny-gold so it
   reads as a chunky barber-pole diagonal, not a smooth orange line. Test: blur the 32px chip — you
   should still see a black-and-gold striped diagonal. The BLACK stripes are the carrier; cream/
   tawny alone won't separate against either sky.
2. **Open the top of the value ladder.** Third-eye core (252) vs crown bone (240) is only ~12 lum
   apart, and the crown is the largest bright mass so the eye goes there. Push the crown-skull bone
   DOWN ~15-20% so the arc reads as the dimmest tier (locked ladder: third-eye → palm-skulls →
   crown DIMMEST); optionally tighten the third-eye to a smaller hotter near-white core + green-gold
   rim so it out-punches by a clear gap.
3. **Preserve the six-arm FAN silhouette at 32px.** The arms collapse into one horizontal bar —
   the radial-fan identity is lost small. Angularly separate the outer arms so 2-3 distinct spokes
   per side break the silhouette at 32px (don't add detail — keep the downscaled edge spoked).
4. **Deliver the pelt as dense ornament so the torso isn't near-naked.** Between the sash and the
   legs the body is plain bone. Wrap a visible striped tiger-hide skirt/thigh-wrap (or hide draping
   over one shoulder, behind the arms) so the tawny+black mass occupies more of the lower torso —
   also feeds #1 (more striped area = stronger 32px tell).
5. **Make the tiger-FACE buckle legible in the hero.** Right now an indistinct brown lump. Give it
   a minimal tiger read: two eye-dots + a muzzle/nose triangle + two ear-notches, in buckle-brown
   on the tawny sash. May mush at 32px (fine), but at hero it must clearly say "tiger face" — that
   plus the ear-crest is what makes her unmistakably vyaghra.
6. **Tail (locked set item) barely present.** Give it one clear striped segment-curl behind the
   hip, routed behind the arms so it never competes with the palm-skulls.
