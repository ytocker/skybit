# Kadomatsu brood — 5 epic bamboo-plant bosses

A spin-off brood from **[Kadomatsu-Shin](../bamboo_v2_versions/kadomatsu_shin/round_2.png)** (the
New-Year three-culm gate-god, part of the realistic Bamboo v2 set). The brief: *more epic, but **reliably
a bamboo PLANT*** — verbatim, "it is a boss bamboo plant." Every boss keeps Kadomatsu-Shin's signature DNA
— the **diagonal-cut cream hollow-ring mouths** + the **bound fresh-cut culm cluster** — scaled into
grander, mythic forms (architecture, offering-pyre, beast, monolith). Procedural, SS=6, 4–6 hard stepped
value bands (no gradients), radial glow accents only, ink keyline + 1px outline — same pipeline as the parent.

**Centrality spread (the user asked for "both"):** three pure bound-culm plant-clusters (Torii / Kazari /
Moso) + two plant-shaped mythic bamboo-beasts (Tatsu serpent, Shishi guardian) — the bound/fresh-cut culm
material dominates every silhouette, so each reads as a bamboo plant first.

**Shishi-Kadomatsu note:** its 32px in-game color read (day + night) is ship-quality — a bound-culm
four-legged beast crowned with a ring of cream cut-discs. The one unmet gate is a silhouette-QA nicety:
in the pure-black blackout proof the crown top trends to a smooth dome rather than a toothed ring (the
negative-space notches need to pierce the outer disc rims, not the gaps). Invisible as a defect at
gameplay scale; documented in `shishi_kadomatsu/critique_round5.md`.

Each boss yields a clean top↔bottom-mirrored **culm pillar** (node-segment repeat band + slant `cut_cap`
gap-edge). Brainstorm + cull + locked briefs: [`brainstorm_gd.md`](brainstorm_gd.md) ·
[`brainstorm_ad.md`](brainstorm_ad.md) · [`brainstorm_locked5.md`](brainstorm_locked5.md). Per-round
critiques live in each `<slug>/critique_roundN.md`.
