# Leyak-epic — 5 inspired-by bosses

Five late-game boss concepts in the lineage of the shipped **Leyak** (the
bodiless flying head), each carrying the severed-head / trailing-viscera motif
into a different world-mythology silhouette. All ship-ready. Design-only — not
yet wired into the spawn roster.

## Lineage

Each concept is **inspired by the shipped Leyak** — the disembodied head that
flies on its own, dragging what would be its insides behind it. The five reskins
keep that read (a dominant head + a trailing/falling body element that doubles as
the pillar prop) while swapping the cultural silhouette, palette, and the nature
of the trailing element (gut-orbs, doom-banner, tentacle curtain, bark plank,
flame-collar).

Each concept dir holds its full round-by-round trail (`round_N.png` +
critique notes) and standalone renderer. Design-only — not wired into the
spawn roster.
