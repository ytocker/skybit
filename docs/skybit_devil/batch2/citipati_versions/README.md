# Citipati versions — charnel skeleton-lord bosses

![Citipati versions showcase](./showcase.png)

Five new charnel skeleton-lord bosses spun off the shipped Citipati — drawn as
five deliberately distinct silhouette KINDs (serpent-coil, stacked-tower,
radial-fan, spread-wing, seated-throne) so they never collapse back into a row
of skull-men. All five are SHIP-READY.

- **Nagaraja** — a legless/armless bone-cobra serpent-king reared into an
  S-coil, single emerald brow-gem the sole focal — SHIP-READY (final round_2) —
  [./nagaraja](./nagaraja)
- **Stupika** — a walking skull-stupa reliquary lord, only the lowest tier alive
  with sunken lamp-eyes, blind niches stacked above — SHIP-READY (final round_2)
  — [./stupika](./stupika)
- **Mukha-Devi** — a six-armed wrathful bone-mother, big chibi skull framed by a
  low-origin radial arm-fan and a 3-skull tiara — SHIP-READY (final round_2) —
  [./mukha_devi](./mukha_devi)
- **Asthi-Garuda** — a bone-winged sky-eater with a beaked bird-skull and two
  tiered quill-wings spread wide over fat talons — SHIP-READY (final round_3) —
  [./asthi_garuda](./asthi_garuda)
- **Koschei** — a deathless bone-throne king seated on a marrow-throne under an
  iron-spike crown, cupping a single chartreuse soul-egg — SHIP-READY (final
  round_2) — [./koschei](./koschei)
