## Ruling on the GD-flagged grin/body value proximity (NIGHT chip)

ACCEPTABLE — ship as-is. The whole point of round 1's directive #2 was that the
lure must win the value contest and the grin must recede to second. Pushing the
grin's value back up to make it crisp on the night chip would directly re-open
the focal inversion I gated on. The silhouette (unmistakable underbite maw
shape) plus the dominant lure carry the gameplay-scale read perfectly; the grin
reading as a subtle dark band at 32px night is correct value discipline, not a
defect. Do NOT brighten the grin to "rescue" it. If the GD wants a touch more
maw definition at zero focal cost, the only safe move is a hair more value
separation in the ink KEYLINE around the lip (darker line, not lighter fill) —
but this is optional polish, not required for ship.
