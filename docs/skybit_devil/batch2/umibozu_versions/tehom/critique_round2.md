  continuous spiral whorl. The KIND is now unmistakable and on-brief.
- **Weakest:** the eye-core/bone-lid HALO. In the 4x value blow-up the brightest mass

## The single most important remaining fix (RULING on the GD's flag)

**Knock the halo back — YES.** Pull the eye-glow + bone-lid value down so the dark
shell wins the eye-zone and only the IRIS (dark slit + tight bone rim) carries the
focal. Concretely:
- Shrink the white glow radius around the iris to roughly the lid footprint — no soft
  bloom spilling onto the whorl or the shell body.
- Drop the lid/sclera from near-white toward a controlled bone-cream `(214,206,182)`
  so it sits a clear step BELOW pure white, and let the dark shell `(46,66,84)` /
  `(26,40,54)` re-own the area immediately around the lid.
- Keep the iris CONTRAST high (dark vertical slit on the bone lid) so the charm survives
  smoothscale without leaning on the glow — the eye reads because the slit is crisp,
  not because the socket is hot.
- Re-check the 4x value blow-up: the iris + a thin whorl highlight should be the only
  true high-value pips. Right now the halo is the brightest object on the egg; after
  the fix the whorl and the crack should out-read it, with the iris as the sharp accent.
