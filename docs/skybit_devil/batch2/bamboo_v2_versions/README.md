# Bamboo v2 — realistic bamboo bosses

A second, **realistic** bamboo boss set — a deliberate departure from the first bamboo set
([`../bamboo_versions/`](../bamboo_versions/), chibi + flat + scary-cute), which read too cartoony and
not bamboo-forward enough. This line drops chibi for realistic, botanically-accurate bamboo, rendered
procedurally with the house triad pushed to **4–6 hard stepped value bands per form** (sculpted,
near-volumetric, no smooth gradients), radial glow for accents only, SS=6. A **mix** of "bamboo IS the
body" and "folklore creature built from accurate bamboo."

Five distinct palette families (takenoko-tan / snow-on-sage / blackened-kurochiku / fresh-cut-green /
deep-grove-green-black) × five distinct silhouette KINDs. Each yields a jointed-culm pillar
(node-segment repeat band + detachable gap-edge cap, bottom-rooted). Distinctness holds vs the four
shipped broods, the roster green lanes (Cernun / Kappa / Kitsune / Haedung / Tlaloc-Citipati), and the
superseded chibi bamboo 5.
