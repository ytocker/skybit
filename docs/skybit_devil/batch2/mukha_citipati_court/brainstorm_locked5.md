# mukha_citipati_court — LOCKED 5 (per-sister briefs)

Five SISTER bone-deities built from the **Mukha-Devi** + **Citipati** references. Tight
adherence to the user's instructions; novelty only on the open axes (body base / ornament
set / palette / skull treatment). Answers the prior brood's **"naked"** rejection with dense,
researched Tibetan wrathful-deity ornament, gold-on-bone, higher resolution.

## LOCKED on ALL FIVE (non-negotiable)
1. **Mukha-Devi six-arm radial fan** (clone `draw_arm_fan`; low-origin, ~[100,64,28]° off
   vertical, none straight up — crown sky stays open).
2. **Six open PALMS each cradling a TINY SKULL** (replaces Mukha's relic-discs) — the motif.
3. **Fused above-head SKULL-CROWN:** the Citipati 5-skull arc-SWEEP AND the Mukha tiara-BAND
   across the brow, TOGETHER (a plain arc alone = fail; show both crown languages).
4. **Dense ornament — never naked.** Each sister wraps every surface in its ornament SET.
5. **Value ladder:** third-eye = single brightest pixel → six palm-skulls = mid → crown
   skulls + garland heads = dimmest. **Glow only on third-eye + crown-centre skull.**
6. **Two-scale ornament:** full brocade/inlay/scale at HERO; at true 32px collapse to
   simplified-but-dense, with ONE named element carrying the gameplay silhouette.
7. **Higher resolution:** SS=8, larger hero canvas, + a standalone hi-res hero export
   (`round_N_hero.png`, ≈1024px tall). Standard sheet too (hero + mirrored pillar + true-32px
   DAY+NIGHT chips + blackout proof + palette strip). Flat triad + 1–2px ink keyline (28,22,26)
   + 1px grown outline; chibi scary-cute (cuteness in PROPORTION only); procedural-only.

**Body-base split: 3 Citipati / 2 Mukha.** Clone Citipati's tall rib-barrel dancing torso
(4 rib-band arcs, cocked hip, `bone_limb`, `crown_skull`, `flame_halo`) and Mukha's squat
rib-barrel + wide 6-petal lotus base (`tiara_skull`, lotus). **GATE every round:** holds all
7 locked items; reads as a RICH, professional bone-deity (reject any bare-bone round); the
six-arm fan + six palm-skulls + fused crown + the ornament set all read DAY+NIGHT at true
32px; clean mirrored pillar grounded in the sister's own forms. Push each to SHIP-READY
(safety cap ≈5 designer rounds).

### 1. asthi_dakini — bone-jewel sky-dancer  (CITIPATI body)
- **Ornament SET:** multi-strand bone-bead jewelry — 3-row choker + long swag necklace +
  beaded armlets/bracelets/anklets + wheel earrings + beaded girdle (bead-lattice over every
  surface).
- **Palette:** cool moonlit bone, pushed DARKER `~(120,134,162)` so beads read light-on-dark
  + icy-cyan + pale-gold. **Carry the texture with WARM gold spacer-pips** (value+hue+CB-safe).
- **Crown:** wide airy 6-skull arc + the Mukha tiara-band; crown skulls a notch warmer/darker
  than the body so they hold against open sky.
- **Focal:** cyan third-eye slit. **32px element:** the bead-girdle + choker bands (bold rows).
- **Lock:** the #1 tonal-collapse risk — never let the only contrast be cyan-on-blue.
