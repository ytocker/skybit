## Set-wide directives (write into ALL five briefs)
- **TRUE FUSION crown:** a plain 5-skull arc alone reads as the Citipati reference, NOT a
  fusion. Every crown must show BOTH the Citipati arc-sweep AND the Mukha tiara-BAND seated
  across the brow, together.
- **Value ladder (focal discipline):** third-eye = single brightest pixel → the six
  palm-skulls = mid → crown skulls + any garland heads = dimmest. Never three competing
  skull-brightnesses in the face zone.
- **Two-scale ornament rule:** dense brocade/inlay/scale detail at HERO; at true 32px each
  sister collapses to a *simplified-but-dense* version where ONE element carries the gameplay
  silhouette. State which element survives to 32px in each brief.
- **Glow restraint = professional:** glow confined to the third-eye + the crown CENTRE skull
  only. Ornament reads by drawn value / gold inlay, NOT by bloom (both references over-glow).
- **Reverent, not flippant:** the cuteness lives in PROPORTION only; severed-head garlands /
  bone ornament stay ornate and reverent. Gold-on-bone + jewel = the high-end tell.

## Ranking (strongest first)
1. **mundamala_mata** — garland-of-heads framing the face is the best non-naked device (fills
   chest + sky beside the crown, reads as one bold swag at 32px). Strongest concept.
2. **vajra_rakta** — billowing patterned silk gives the most gestural mass without adding
   skull-count to the focal zone; flame-ring + tall crown = unmistakably the fierce sister.
3. **ratna_padmini** — only full enclosing halo; treasure palette is the most high-end read;
   gentlest contrast partner. Highest small-element COUNT → biggest mush risk.
4. **naga_kapali** — best single hook (green serpent diagonal) and the only cool-green;
   rearing-naga crown is a distinct tell. Risk: two snakes + cups + scale-pips = thin line.
5. **asthi_dakini** — gorgeous cool-ice palette, densest texture, BUT highest tonal-collapse
   risk (low-chroma beads on low-chroma bone → grey smear = "naked" in disguise).

## FIX — per-sister punch list
1. **asthi_dakini (top priority):** push bone SHADE darker (~(120,134,162)) so the bead
   lattice reads light-on-dark, and/or carry the texture with WARM gold spacer-pips on cool
   bone (value AND hue separation, colorblind-safe). Crown skulls a notch warmer/darker than
   the body so the crown holds against open sky.
2. **vajra_rakta:** gold vajra-cross brocade mushes at 32px → carry a sparse regular gold-dot
   lattice at gameplay scale, full brocade hero-only. Flame-ring stays OPEN (don't close it
   behind the crown and kill the open-sky wedge the fan needs).
3. **naga_kapali:** thin serpent + scale-pips + cups are sub-pixel at 32px → collapse to ONE
   bold green diagonal band + the green choker at gameplay scale; rearing-naga crown hood is
   the 32px serpent read. Darken verdigris so the coil reads by value, not hue alone.
4. **mundamala_mata:** garland heads dimmer than BOTH the third-eye and the palm-skulls (the
   value ladder). Guard hard against rose drifting back toward the rejected Mukha magenta —
   oxblood cord + gold spacers dominate; rose glow sparingly.
5. **ratna_padmini (highest element count):** inlay + tassels + bells + gem-per-petal + halo
   WILL mush → the enclosing flame-halo ring carries the 32px silhouette; inlay/tassels are
   hero-only. Protect the turquoise+gold as the brood's premium contrast piece.

## Net
Lock all five. The only gap to SHIP-READY is the explicit two-scale ornament rule + value
ladder + true-fusion crown baked into the briefs, so dense never becomes illegible.
