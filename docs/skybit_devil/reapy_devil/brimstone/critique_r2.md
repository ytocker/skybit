# BRIMSTONE (A2) — round 2 critique (final critique of loop)

VERDICT: ITERATE

The glow cut LANDED and the concept is now itself. At 1x day and 1x night the
figure reads as cracked charcoal-basalt rock — dark mass dominant, hot seams as
secondary cracks — exactly the "rock cracked, not rock on fire" target. The
grayscale cell proves the skull stands on construction alone. The column prop is
the cleanest, most literal pillar in the set. This is 90% shipped and clears the
bar on color, distinctness, prop, and 1x legibility. I'm holding it at ITERATE
(not SHIP-READY) for ONE reason: the BOSS-scale face still wears the round-disc
owl eyes from round 1, contradicting the corrected 1x sockets. That's a one-knob
consistency fix, not a rework — fold it in on the final pass and this ships.

## Strongest / weakest

- **Strongest:** value structure on the 1x panels. Charcoal-basalt now carries
  ~65-70% of the value mass on the day sky; the magma seams read as light
  leaking from cracks, not a wash. The Soulforge firewall is restored — this is
  unmistakably STONE-dominant-with-seams, not contained-forge-orange. Distinctness
  PASS: still the set's only angular/faceted skull, and the palette no longer
  collides with A-tier warm skulls.
- **Weakest:** the BOSS panel face is out of sync with the 1x face. The sockets
  there are still large full-orange round discs with a horizontal lid-slit — that
  still reads owl / sleepy-lidded at showcase scale. The 1x panels show the
  CORRECT empty-ink-cavity-with-low-ember socket. One of these is the old code
  path; unify on the 1x version everywhere.

## KEEP (locked — do not touch)

- The 1x day/night socket: dark angular cavity, mostly ink, small ember pooled
  low. This is the correct skull read. Make it the ONLY socket.
- Seam discipline: 1 bold body zigzag, 3 cranial, joint-welled column crack with
  basalt banding dominant. The "few decisive lines" guardrail is satisfied.
- Charcoal value anchor + faceted crag silhouette + chunky square teeth + chipped
  tooth. The grayscale carries the skull with zero magma — exactly right.
- The basalt hex column + brazier cap + top<->bottom mirror, brazier fire welling
  into the gap. Clean and tileable at 82px native. Best prop in the set.

## FIX (ranked — short punch list for the final pass)

1. **UNIFY THE SOCKET — kill the boss-panel owl disc (Readability / Identity).**
   The showcase face still draws the full round orange iris-disc with a horizontal
   lid slit; the 1x panels correctly draw a dark ink cavity with a low ember. Drive
   BOTH from the same code so the boss render shows empty ink cavities with a small
   low ember — no full-disc fill, no horizontal lid line. The lid-slit in
   particular is what tips it sleepy/owl. This is the single thing standing between
   this and ship-ready.

2. **GRIN: cool the fill ~15-20%, keep the shape (Polish / Color).** At boss scale
   the magma grin-bed is still a hot yellow-cored band — slightly louder than the
   "quiet blush" thesis. Pull the grin's inner value down a touch (deeper orange
   core, less yellow hotspot) so the teeth-as-basalt-blocks stay the hero and the
   glow is a blush behind them, not a lightbar. At 1x it's already close; this is
   a showcase-scale refinement so the two scales agree.

3. **CHIN/JAW EMBER DOT (minor, Polish).** The small round ember under the chin
   (boss panel) floats as a stray orange blob disconnected from the seam logic.
   Either tie it to a visible neck seam or drop it — at 1x it just reads as a
   stray dot.

## Distinctness check (vs the set + roster) — PASS

- Only angular/faceted skull in the set; construction is unique. PASS.
- Soulforge firewall HELD: Brimstone now reads stone-dominant-with-seams vs
  Soulforge's soot-dominant-with-sparks. The round-1 orange-blob collision is gone.
- Owl/jack-o-lantern collision with Big Reapy resolved at 1x; fix 1 closes it at
  boss scale too.

## Bottom line

Everything that ships in-game (the 1x day/night read) is already at bar. The only
blocker is the boss-panel face lagging behind the corrected 1x socket. Sync the
socket (fix 1), nudge the grin (fix 2), and this is a SHIP. Implement fix 1 and
I'd sign it.
